# Corner Shop

A small web shop used as a sandbox workspace for Shahd's tool-use training data.

- `src/cart.js` keeps the shopping cart and computes totals.
- `src/api.js` talks to the backend.
- `styles/main.css` holds the design tokens and base styles.
- `db/schema.sql` defines the products and orders tables.

Run `npm start` to serve the shop on port 3000.
